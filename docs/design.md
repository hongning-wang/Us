# Us inside Instagram

Keep Instagram's composer, message layout, and native controls intact. Do not add a separate generation/result card or a persistent composer button. The user replies normally and types `/us …`. `Make this us` and `Continue` remain small text shortcuts beneath the corresponding media; they open the native reply composer with `/us` and a suggested instruction.

Show preparation, generation, and sending inside a Reel-shaped media placeholder in the conversation. It must not resize or restructure Instagram's composer. When generation completes, automatically upload and send the real video in the captured conversation. Wait if the user has another draft or attachment. Never send the raw `/us` command.

First photo confirmation is the only required setup dialog. Save it for the current Instagram identity and reuse it on later requests. `/us settings` opens optional photo replacement and memory controls. Never reuse one person's photo for the friend.

A chosen prerecorded fallback stays explicitly labeled as a demo. Errors offer concise retry controls without a new dashboard.

Generation appears as a 200px-wide, 9:16 media placeholder at the end of the Instagram conversation, with rounded corners, a spinner, and “Generating…”. It switches to “Sending…” during native upload and disappears once the real attachment is confirmed. It adds no composer controls and does not carry the previous message’s Seen label.

Existing-video requests default to minimal identity substitution. Their prompt preserves the source scene, action, framing, style, dialogue and audio; shared-memory jokes or new settings are not inserted. “What happens next?” extends that same scene naturally. Shared relationship memory continues to guide unreferenced text requests.

The active Instagram account and selected one-to-one chat determine the experience. The share action is simply “Make this us,” placed inside the native Send footer, and uses the currently selected person. It carries optional steering into that chat’s normal composer. Account/chat-scoped history and jobs replace the old single designated conversation.
